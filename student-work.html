Set Up Google Form

Create a Google Form with these fields:

  • Student Information:
    • Full Name (or pen name)
    • Email Address
    • Class/Level
  • Submission Type:
    • Type: Poetry or Artwork (multiple choice)
  • For Poetry:
    • Poem Title
    • Poem Text (paragraph)
  • For Artwork:
    • Artwork Title
    • Medium (e.g., Digital, Watercolor, Pencil)
    • Description
    • Upload Image (file upload)
  • Permissions:
    • I give permission for AESOP to display my work (checkbox)
